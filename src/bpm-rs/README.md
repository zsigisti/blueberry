# bpm

Blueberry's package manager, in Rust. It replaced the old C bpm and still
uses the same db, cache and index on disk, so either one works on a live system.

## How it works

Packages are `.bpm` files (old `.pkg.tar.zst` ones still install) fetched over
HTTPS from the mirrors in `/etc/bpm/repos.conf`. `bpm update` pulls
`bpm.index` plus `bpm.index.sig`, checks the ed25519 signature against the key
compiled into the binary, and refuses an index whose serial is older than the
last one it accepted. The index has every package's sha256, and every download
gets checked against it.

Installs stream zstd -> tar -> disk, so even gcc goes in with a few MB of RAM.
Each file is written next to its target and renamed over it, which means bpm can
replace running binaries (itself included) without ETXTBSY. Config files listed
under `backup` are never clobbered: if you edited one and the package changed
it too, the new version lands next to it as `.bpmnew`.

## Commands

`install`/`in`, `remove`/`rm`, `autoremove`, `update`/`up`, `upgrade`,
`outdated`, `audit`, `rollback`/`rb`, `downgrade`/`dg`, `search`/`se`,
`list`/`ls`, `info`, `why`, `depends`/`deptree`, `files`, `clean`.
`bpm help` has the one-line summaries and `man bpm` the rest.

- `-f`/`--force` skips the space, file-conflict and reverse-dep checks.
- `BPM_ROOT=<dir>` installs into a staging root (scriptlets and ldconfig chroot into it).
- `BPM_NO_SCRIPTLETS` skips install hooks and service enablement.
- `BPM_ALLOW_UNSIGNED` accepts an unsigned index. Dev only.

`bpm list` (`name version`) and `bpm outdated` (`name\tinstalled\tavailable`)
are parsed by the web console and the tests, so leave their output alone.

## Building

```sh
cargo build --release    # target/release/bpm
cargo test
```

Deps are `ureq` (rustls), `zstd`, `tar`, `sha2`, `libc` and `ed25519-dalek`.
The release binary only links libc and libgcc_s, zstd is bundled in.

The repo package is `packages/bpm/bpm.toml`, and `tools/pkg/build-bpm.sh` builds
it into the image and initramfs. On a running system, `bpm install bpm` updates it.
The signing key in `src/repokey.rs` is generated by `tools/pkg/mkrepokey.sh`, so
don't edit that one by hand.
